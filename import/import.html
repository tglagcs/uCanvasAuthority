Export

Save your current settings to a file, to keep a backup or move them to another install.

Import

Select one or more exported files. Each file is recognized automatically: a CanvasBlocker settings export (.json), a uMatrix full backup (.json), or a uMatrix "my rules" text export (.txt). Port Authority has no export format and is not covered here.

    Importing a uMatrix full backup reloads the whole extension once applied. If you are also importing other files in this batch, they are applied first.
